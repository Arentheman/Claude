# Нейро-прыгун

Бот сам играет в Doodle-Jump-подобную игру из Telegram mini-app и с каждой попыткой
играет лучше. Он нажимает те же кнопки, что и человек: **A / D** — влево и вправо,
**клик левой кнопкой** по врагу — бросок.

## Как пользоваться

1. Скачайте **NeuroJumper.exe** со страницы Releases этого репозитория.
2. Откройте игру в Telegram Desktop так, чтобы она была видна целиком.
3. Запустите NeuroJumper.exe и нажмите **«Учиться»**.
   Бот сам найдёт игру и встанет окном рядом с ней.
4. Начните игру. Дальше бот играет сам, пока персонаж не упадёт.
5. **После первого падения** один раз сами нажмите в игре «Играть снова».
   Бот запомнит, куда вы нажали, и дальше будет перезапускать игру сам.

Пока бот учится, не трогайте мышь и клавиатуру.
**F9** — пауза, **F10** — стоп. Прогресс сохраняется рядом с exe
(`population.json`), так что можно закрыть и продолжить позже.

Другие кнопки:
- **«Играть лучшей сетью»** — бот играет лучшей найденной сетью и больше не учится.
- **«Проверить зрение»** — бот ничего не нажимает, только показывает в своём окне,
  что распознал: платформы в зелёных рамках, персонаж в синей, враги в красных.

Windows может предупредить, что программа от неизвестного издателя:
нажмите «Подробнее» → «Выполнить в любом случае».

## Как он работает

1. **Смотрит.** Десятки раз в секунду снимает область игры и находит персонажа,
   платформы и врагов.
2. **Думает.** Нейросеть (19 входов → 12 нейронов → 2 выхода) получает скорость
   персонажа, три следующие платформы над той, от которой он оттолкнулся
   (с учётом прохода сквозь край экрана), и ближайшего врага.
3. **Жмёт.** Зажимает A или D и кликает по врагу.
4. **Учится.** Нейроэволюция: в поколении 12 сетей, каждая играет одну попытку.
   Очки = высота + 250 за врага − 3 за бросок. 3 лучшие сети переходят дальше
   как есть, остальные — их копии с мутациями.

В реальной игре каждая попытка идёт в реальном времени, поэтому сети заранее
обучены в симуляторе (`pretrained.json`) и дальше дообучаются под настоящую игру.

## Для разработчиков

Запуск из исходников (Python 3.10+):
```
pip install -r requirements.txt
python gui.py                # окно
python bot.py train          # то же из консоли (нужен python bot.py setup)
python bot.py debug --image screenshot.png   # проверить распознавание на скриншоте
```
Предобучение в симуляторе (Node.js): `node pretrain/pretrain.js 80`.
Exe собирается GitHub Actions (`.github/workflows/build-jump-bot.yml`).
