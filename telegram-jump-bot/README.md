# Нейро-бот для прыгалки в Telegram

Бот сам играет в Doodle-Jump-подобную игру из Telegram mini-app и с каждой попыткой
играет лучше. Управление то же, что у человека: **A / D** — влево и вправо,
**клик левой кнопкой** по врагу — бросок.

## Как он работает

1. **Смотрит.** Около 30 раз в секунду снимает область игры на экране и находит
   персонажа, платформы (тёмные полоски травы) и врагов (например, розовую свинью).
2. **Думает.** Нейросеть (19 входов → 12 нейронов → 2 выхода) получает скорость
   персонажа, три следующие платформы над той, от которой он оттолкнулся
   (с учётом прохода сквозь край экрана), и ближайшего врага.
3. **Жмёт.** Зажимает A или D и кликает по врагу, если сеть решила бросить.
4. **Учится.** Нейроэволюция: в поколении 12 сетей, каждая играет одну попытку.
   Очки = высота + 250 за убитого врага − 3 за бросок. 3 лучшие сети переходят
   в следующее поколение как есть, остальные 9 — их копии с мутациями.

Учиться с нуля в реальной игре долго: одна попытка идёт в реальном времени.
Поэтому сети заранее обучены в симуляторе (`pretrained.json`), и бот начинает
не со случайных движений, а дообучается под настоящую игру.

## Установка (Windows)

Нужен Python 3.10+.

```
cd telegram-jump-bot
pip install -r requirements.txt
```

## Запуск

1. **Настройка.** Откройте игру в Telegram Desktop, затем:
   ```
   python bot.py setup
   ```
   - Нажмите **F8**, когда игра на экране. Бот найдёт область игры и сохранит
     картинку `setup_check.png`: на ней должны быть рамки вокруг платформ (зелёные),
     персонажа (синяя) и врагов (красные).
   - Дайте персонажу упасть. На экране проигрыша наведите мышь на кнопку
     «Играть снова» и нажмите **F8** (если кнопок несколько — F8 на каждой
     по порядку). Затем **F9**.

2. **Проверка.** Бот ничего не нажимает, только показывает, что видит:
   ```
   python bot.py debug
   ```
   Поиграйте сами и посмотрите в окно: персонаж должен быть в синей рамке,
   а цифры 1–3 — над следующими платформами.

3. **Обучение:**
   ```
   python bot.py train
   ```
   Кликните по окну игры в первые 3 секунды. Прогресс сохраняется в
   `population.json`: можно остановить и продолжить позже.

4. **Игра лучшей сетью:**
   ```
   python bot.py play
   ```

Горячие клавиши: **F9** — пауза / продолжить, **F10** — выход.
Окно «Что видит бот» не должно перекрывать игру.

## Если что-то не так

- **Неверная область игры.** Поправьте `region` в `config.json`
  (left, top, width, height в пикселях экрана).
- **Персонаж не находится или путается с врагом.** Пришлите `setup_check.png`
  или скриншот — подстрою распознавание.
- **Клавиши не доходят до игры.** Кликните по игре мышью, чтобы фокус был
  в ней, и запустите консоль от того же пользователя (не от администратора).
- **Заново с нуля.** Удалите `population.json`. Чтобы учиться совсем без
  предобучения, удалите ещё и `pretrained.json`.

## Предобучение в симуляторе

Нужен Node.js:
```
node pretrain/pretrain.js 80
```
Перезапишет `pretrained.json`.
